# 裂缝及修补数据集复核标注工具 (Windows版配置指南)

本项目旨在提供一个轻量级、高效的路面裂缝图像及其对应掩码（Mask）的精细化修改、查验与分类梳理工具。在完成自动预标注（去噪与平滑）之后，我们将依此进行专家级最终人工复核。

---

## 🚀 核心功能与亮点

- **实时可视化**：将半透明红色的 Mask 完美叠加在原灰度图像之上，随时看清底层路面纹理结构。
- **动态修图（未实现，预留能力架构）**：支持使用自定义大小的画笔与橡皮擦对生成的边缘或空洞进行实时手动画涂补救修改。
- **自动分类及分拣隔离（核心功能）**：
  在高速浏览图片时，一键判断分类并**自动将此套图像+Mask剪切迁移**至与其性质匹配的子集目录内：
  - `[R] 修补` (Repaired)
  - `[T] 真裂缝` (True Crack)
  - `[F] 伪裂缝` (False Crack)
- **批量式连续处理**：通过文件夹一键式加载，内置进出队列，消除重复操作劳动。

## 🛠️ Windows 环境配置指南（基于 VS Code）

相较于 macOS M4 上的 Tkinter Tcl API 版本冲突，在 Windows 环境下运行本 Python 自带 GUI 工具通常更加丝滑。

### 1. 准备前置环境

确保您的电脑（如 Thinkpad）满足以下基础开发环境：
* **Python**：已安装 Python 3.9 或更高版本（安装时请务必勾选 `"Add Python to PATH"`）。
* **VS Code**：已安装，并推荐在拓展商店中搜索并安装官方的 **`Python`** 扩展插件。

### 2. 下载及导入项目

1. 将包含此工具的项目文件夹（如 `auto_labeling_workspace` 或独立的 `mask_label` 文件夹）拷贝到电脑的某个盘符中。
2. 打开 VS Code，点击菜单栏 `文件 (File) -> 打开文件夹 (Open Folder)`，选择您的项目根目录。

### 3. 构建虚拟环境并安装依赖库

为了保证您的电脑不被第三方包干扰并顺利运行 OpenCV，**极度建议**创建一个虚拟环境：

1. 在 VS Code 的顶部菜单中点击 `终端 (Terminal) -> 新建终端 (New Terminal)`。
2. 在底部的控制台中，执行以下命令以创建一个名为 `.venv` 的虚拟环境：
   ```powershell
   python -m venv .venv
   ```
3. 激活刚刚建立的虚拟环境：
   ```powershell
   # PowerShell 环境下：
   .\.venv\Scripts\Activate.ps1
   
   # （如果因为系统执行策略报错，请以管理员身份打开一个 PowerShell，运行 Set-ExecutionPolicy Unrestricted 然后按 Y 回车即可，然后再回来激活执行）
   ```
   *成功激活后，您终端的输入行最前面会出现一个绿色的 `(.venv)` 标志。*

4. 安装 GUI 渲染和图像处理所必需的三个 Python 包：
   ```powershell
   pip install pillow opencv-python numpy
   ```

### 4. 运行软件

依赖包安装完成后，仍然在这个带有 `(.venv)` 标志的终端里输入以下指令，唤醒工具界面：

```powershell
python path\to\mask_label\crack_labeler.py
# （请将 path\to 替换为您实际所在的相对路径，例如 python .\mask_label\crack_labeler.py）
```

## 🖱️ 交互说明与快捷键速查

软件启动后，点击左上角主菜单的 **「文件 -> 加载项目文件夹」**，选择例如 `DetRes00` 这样同时包含 `images` 和 `masks` 子文件夹的根目录，即可载入整批图片。

| 动作意图 | 对应快捷键 | 详细行为 |
| :--- | :--- | :--- |
| **临时查看裸露原图** | **按住 `S` 键** | 掩码瞬间变为完全透明 (0%)。松开 `S` 键即可恢复显示。 |
| **切换上一张** | `A` 或 `←` 或 `↑` | 返回上一张看过的图 |
| **切换下一张** | `D` 或 `→` 或 `↓` | 当前图片判定没问题，或不属于特殊三种分类时，跳过此图进入下一张 |
| **划分为【修补】** | `R` 键 (Repaired) | 当前原图+Mask立刻移动至 `xxx_repaired/` 专属存放区，并切下张 |
| **划分为【真裂缝】** | `T` 键 (True) | 当前原图+Mask立刻移动至 `xxx_true_crack/` 专属存放区，并切下张 |
| **划分为【伪裂缝】** | `F` 键 (False) | 当前原图+Mask立刻移动至 `xxx_false_crack/` 专属存放区，并切下张 |
| **切换工具状态** | `W` 键 | 切换 画笔/橡皮擦 状态 |
| **抹除当前项（作废）**| `Delete` 或 `Backspace`| 彻底将该图与掩码移入物理回收站或删除 |

---

> 💡 **效率小贴士：分类操作机制**
> 在您按下 `R`, `T`, `F` 进行流转整理时，对应的图片就**不再属于当前的审核列表了**（它“搬家”了）。因此当您将这个分包里所有的图片全盘过完一遍后，当前你所停留在的原始那个 `images/` 和 `masks/` 里面，**剩下来的就是最后那部分无需分类搬家、最纯粹的剩余基础裂缝样本。**
