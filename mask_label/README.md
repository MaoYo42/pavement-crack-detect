# 路面裂缝分割标注软件

一个功能完善的图像标注工具，专为路面裂缝的分割标注设计。

## 功能特点

### 基础功能
- 加载和显示图像
- 加载和编辑mask标签
- 画笔工具：在mask上绘制裂缝区域（白色255）
- 橡皮擦工具：擦除mask上的标注（黑色0）
- 可调节画笔大小（1-20像素）
- 可调节mask透明度（0-1）
- 保存编辑后的mask

### 批量处理功能
- 加载图像文件夹：批量加载整个文件夹的图像
- 加载Mask文件夹：自动匹配对应的mask文件
- 上一张/下一张导航：快速切换图像
- 自动保存：切换图像时自动保存当前mask
- 文件计数显示：显示当前进度（如 5/20）

### 高级功能
- 撤回操作：支持最多50步撤回
- 删除图像：删除当前图像和对应的mask文件
- 鼠标滚轮缩放：0.1x - 10x 缩放范围，以鼠标位置为中心
- 临时隐藏mask：按住S键查看原图

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 启动程序
```bash
python crack_labeler.py
```

### 批量标注流程
1. 点击"文件" → "加载图像文件夹"，选择包含路面图像的文件夹
2. 点击"文件" → "加载Mask文件夹"，选择存放mask的文件夹
3. 使用工具进行标注
4. 使用快捷键快速切换图像，自动保存

### 标注技巧
1. **粗标注**：使用较大画笔（10-20像素）快速标注主要裂缝
2. **精细标注**：滚轮放大图像，使用小画笔（1-5像素）标注细节
3. **查看原图**：按住S键临时隐藏mask，确认裂缝位置
4. **快速切换**：使用A/D键或箭头键快速浏览图像

## 快捷键

### 导航控制
- `A` 或 `←` 或 `↑`：上一张图像
- `D` 或 `→` 或 `↓`：下一张图像
- `Delete` 或 `Backspace`：删除当前图像和mask

### 工具控制
- `W`：切换画笔/橡皮擦工具
- `S`（按住）：临时隐藏mask（透明度变为0）
- `S`（放开）：恢复mask显示

### 编辑控制
- `Command+Z` (Mac) 或 `Ctrl+Z` (Windows/Linux)：撤回操作

### 鼠标操作
- 左键拖动：绘制或擦除
- 滚轮向上：放大图像（1.1倍）
- 滚轮向下：缩小图像（0.9倍）
- 触控板双指缩放：放大/缩小图像（Mac支持）

## 文件格式

### 支持的图像格式
- JPG, JPEG, PNG, BMP

### Mask文件
- 保存格式：PNG（推荐，无损压缩）
- 像素值：白色（255）表示裂缝，黑色（0）表示背景
- 文件命名：与原图同名，扩展名为.png

## 注意事项

1. **自动保存**：切换图像时会自动保存当前mask到mask文件夹
2. **文件匹配**：mask文件名应与图像文件名相同（不含扩展名）
3. **删除确认**：删除图像前会弹出确认对话框
4. **撤回限制**：每张图像最多保存50步撤回历史
5. **缩放重置**：切换图像时自动重置缩放为1.0x

## 推荐工作流程

### 单人标注
1. 加载图像文件夹和mask文件夹
2. 从第一张开始标注
3. 使用D键快速切换到下一张
4. 对于质量差的图像，按Delete删除

### 质量检查
1. 加载已标注的图像和mask文件夹
2. 使用A/D键快速浏览
3. 按住S键对比原图和mask
4. 发现错误时使用画笔/橡皮擦修正

## 常见问题

**Q: 如何标注很细的裂缝？**
A: 使用鼠标滚轮放大图像，然后使用1-3像素的小画笔进行精细标注。

**Q: 如何快速查看标注效果？**
A: 按住S键临时隐藏mask，查看原图；放开S键恢复显示。

**Q: 误删了图像怎么办？**
A: 删除操作会直接删除文件，建议提前备份重要数据。

**Q: mask透明度调节有什么用？**
A: 调节透明度可以更好地看到原图和mask的叠加效果，找到最舒适的标注视角。

**Q: 撤回功能有限制吗？**
A: 每张图像最多保存50步操作历史，切换图像时会清空撤回栈。
